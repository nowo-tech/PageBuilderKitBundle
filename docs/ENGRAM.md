# Engram — AI persistent memory

Repository-local **product spec** and **`REQ-*`** traceability are described in [Spec-driven development](SPEC-DRIVEN-DEVELOPMENT.md).

This repository is **prepared to use Engram** with Cursor. Configuration: `.cursor/mcp.json` registers the Engram MCP server (`engram mcp`).

## Quick links

- Install: `npm install -g engram-sdk` then `engram init`
- Docs: [engram.fyi](https://www.engram.fyi/docs)
- Full workflow: see [SPEC-DRIVEN-DEVELOPMENT.md](SPEC-DRIVEN-DEVELOPMENT.md)
